# Quest learning content

`src/content.mjs` provides nine campaign lessons and four journal lessons.
It contains language examples and contextual multiple-choice practice only.
It does not read or write any external study notes.

| World | Lessons |
| --- | --- |
| Wordwood | 議, 論, 関係 contrasted with 環境 |
| Workshop | 治す / 直す, 治る / 直る, ～恐れがある |
| Sky | ～に基づいて, ～ために, ～ように |
| Journal | 民, ～により, 実, 米 |

Each lesson has a meaning, a Romanized Nepalish memory hook, a focused
explanation, Japanese examples with romaji and English, and exactly three
questions. Practice follows teaching, so a correct game response is practice
with a hint, not proof of unaided retention. Campaign progress belongs to the
game and must not be reported as the learner's authoritative study evidence.

## Language conventions

- Romaji uses `ou` or `uu` for the long vowels in these words. `故障` is
  **koshou**, not `koushou`; `住民` is **juumin**.
- `基づいて` is written `もとづいて` and represented as **motozuite**. Keep
  the distinction between written `づ` and `つ`.
- `実験` is **jikken**; `事件` is **jiken**. Both spelling and consonant
  length differ.
- `治す` / `直す` are transitive; `治る` / `直る` are intransitive.
  An intransitive repaired-result sentence does not claim an object fixed itself.
- `～ために` and `～ように` can overlap in some contexts. The questions
  avoid marking every alternative use of `ために` inherently wrong.
- `～により` is taught here in its formal cause use; means and agent uses
  exist but are outside these questions. `～ために` also has a cause use
  outside this lesson's purpose examples.
- Hooks are memory aids, not claims about kanji etymology.
- Engineering and workplace sentences are language examples, not operating
  procedures for real equipment.

## Standalone content

The bundled lessons are a fixed review pack with engineering and workplace
examples. No personal study history, learner responses, or external study files
are included. Game discoveries and correct answers describe supported practice,
not independently verified mastery.
